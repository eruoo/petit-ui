# 语义与使用边界

Petit UI 是 **tokens-only** 的视觉基础。导入 CSS 不会自动改变元素外观，也不会生成按钮、卡片或对话框。

## 包负责什么

公共变量描述颜色、圆角、边框宽度、字重与字号的角色。同一个 `surface` 可以用在卡片或输入框；`primary` 表达主操作填充，不绑定某个组件。

[Token 浏览器](/tokens)直接从当前 CSS 读取默认值，并使用内部规范的语义说明。

## 应用负责什么

布局、间距、组件轮廓、字体加载、图片、动效、键盘行为和主题偏好的存储，都由应用负责。这里的茶杯卡片、Cook 徽记和 Reka UI 示例属于文档站，不是 npm 包导出的组件。

| 需要                  | 使用方式                           |
| --------------------- | ---------------------------------- |
| 不依赖框架的视觉变量  | `petit-ui/tokens.css`              |
| Tailwind CSS 4 工具类 | `petit-ui/tailwind.css`            |
| Vue 交互和无样式控件  | 应用自行使用 Vue、Reka UI 等       |
| 茶杯、字体和示例轮廓  | 参考本站源码及[资源来源](/credits) |

## 正文与装饰分开

- 正文用 `foreground`，辅助文字用 `foreground-muted`。禁用色只用于真正不可交互的禁用内容。
- 链接使用 `link` 并保留下划线。金黄 `primary` 是填充色，搭配 `on-primary` 文字。
- `foreground-accent` 只用于常规表面上的大号强调文字：至少 24px，或至少 18.67px 的粗体。它不适合小号正文或链接。
- `border` 是奶油色装饰边。需要辨认的输入框、Checkbox 等功能边界使用 `border-strong`。
- `border-selected` 表达选择，`focus` 表达键盘焦点。选择不能吞掉焦点提示，也不能只用颜色表达状态。

## 颜色组合有范围

默认主题为指定组合检查对比度；任意两种 tokens 搭配并不自动成立。

正文与辅助文字适合页面及中性表面。青灰 `surface-accent` 上优先使用 `foreground`；辅助文字、链接和状态文字放在纸色阅读面。较深青灰 `surface-accent-strong` 不使用浅褐标题。

状态色与对应 `on-*` 成对使用；同时给出文字或图标。覆盖品牌后，需要重新检查正文、悬停、按下和焦点状态。

`error` 文字也可用于 `surface-hover`，供破坏性文字操作悬停时使用。破坏性操作按下时切换到 `error/on-error` 配对。小号 `link` 只承诺页面和普通内容表面，不能直接作为任意菜单悬停、按下状态的文字色。

模态遮罩使用带透明度的 `scrim`，内容面仍用 `surface`。字段校验、破坏性菜单项、状态卡片及组合状态见[常见 UI 状态配方](/guide/states)。

## 大号角色留给控件展示

`font-size-heading`、`font-size-label`、`font-size-action` 来自明显的控件层级。它们不是文档或应用正文的默认字号。本文导航和长文用单独的阅读尺度，展示中的 Cook 才使用大号 action 角色。

`font-weight-display` 的 900 用于最高展示强调；`font-weight-strong` 的 800 包含默认 Cook 主操作和较低的强调层级，不表示“只能用于次级操作”。10px 的 `border-width-frame` 和 8px 的 `border-width-selected` 也是展示厚框，普通输入框和紧凑控件自行选择合适的细边框。

设置字重不等于已经加载了对应字体。本站为英文示例加载 Nunito 可变字体，中文正文使用系统字体。字体文件不进入 token 包。

## 设计边界

默认浅色转译了星布谷地公开界面的奶油纸色、深褐、青灰和金黄关系。Petit UI 不是官方组件库，也不提供官方素材或逐像素复刻。[查看设计来源与许可](/credits)。
